# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Use GitHub Private Vulnerability Reporting for this repository. Do not include
credentials, stream keys, session cookies, viewer-link tokens, recordings, or
other sensitive data in a public issue, discussion, or commit.

Include the affected version, deployment method, a concise description of the
impact, and safe steps to reproduce the issue. The report will be assessed
privately before a fix and disclosure are coordinated.

## Scope

This policy covers the dashboard, API, Docker Compose deployment, official
container images, and documentation maintained in this repository.
